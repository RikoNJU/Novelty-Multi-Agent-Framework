## 补充发现与原因

1. **引用版本未形成可重建输入。** vLLM/Pydantic 使用 latest 路径，索引仅给访问日期；未保存对应文档内容 hash 或版本号。重新打开现在的文档只能证明本次可读，不能证明与 9 月 27 日文字完全一致。
2. **历史来源身份与技术相关性混在一起。** 日报原件缺失，公开论文摘要无法替代私有投递记录。当前可确认的仅是论文身份和摘要机制。
3. **论文机制不是当前库的能力声明。** 调用依赖、局部程序指导、压缩、错误标准、配置来源分别对应不同问题；应以本项目调用链为实现依据。当前具体缺口已经列入 02–06，不需要额外引入图数据库或监督 Agent 才能定位。

本轮没有核验论文实验成绩、完整 PDF 或迁移方案收益；公开资料仅作参考身份与机制边界检查。若要验证任何方案的实际收益，需要先取得用户对补充实验的同意。
