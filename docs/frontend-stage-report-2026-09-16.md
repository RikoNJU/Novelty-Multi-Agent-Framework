### 安全与数据处理

- Markdown 原始 HTML 不执行；危险链接受限；外部链接设置安全属性；不加载报告中的远程图片。
- PDF 使用 PDF.js worker 与 Canvas 渲染，关闭动态求值和注解层。
- 文件名作为文本展示；下载名清理路径分隔符、控制字符及方向控制字符，支持服务端 UTF-8 中文文件名。
- 报告 URL 限制为同源 `/api/novelty/` 路径，读取后验证 MIME 和文件名。
- 不将论文内容、报告正文或访问令牌存入 localStorage；下载 Blob URL 用后释放。
- 不将后端原始异常、密钥或内部路径显示给用户。

以下结果来自本阶段开发过程的最终执行记录；编写本报告时未重复运行测试。

| 验证项 | 命令或方式 | 结果 |

| 类型检查与生产构建 | `pnpm build` | 通过 |
| 单元与组件测试 | `pnpm test` | 7 项通过 |
| 浏览器测试 | `pnpm test:e2e`，使用本机 Chrome | 13 项通过 |
| 基础无障碍 | 浏览器测试内执行 axe 扫描 | 已覆盖页面无违规项 |
| 响应式检查 | 390、768、1440 像素宽度；背景加载失败与 Reduced Motion | 通过；桌面、手机截图已人工检查 |
| 差异格式检查 | `git diff --check` | 通过 |

7 项单元/组件测试覆盖文件类型、大小、数量、空文件、MIME 不匹配、中文下载名、错误归一化、阶段映射、重连退避、缺失论文提示与焦点、键盘/拖放入口，以及 Markdown 安全渲染。

13 项浏览器测试覆盖：

1. 文件提交 → 任务轮询 → 完成 → Markdown 预览与下载，并刷新恢复。
2. 任务查询分别返回 404、422、500 的处理，共 3 项。
3. 断网后重连，避免将网络异常判为任务失败。
4. 报告读取失败后允许重试，并保留完成状态。
5. 手机、平板、桌面布局及无障碍检查，共 3 项。
6. 提交返回 422 后保留文件，允许修改重试。
7. 服务端阶段与补检轮次展示，以及运行失败时隐藏原始异常。
8. 当前结构化结果契约预览，隐藏不存在的下载入口。
9. PDF 本地预览、翻页、缩放及返回后保留文件，并检查运行异常。

浏览器测试使用专用接口拦截，不调用真实文件后端或模型服务。因此，以上结果证明前端在约定响应下的行为通过验证，不代表真实上传、解析、查新、报告下载链路已经联调完成。axe 基础扫描也不等同于完整人工无障碍认证。

### 验证中发现并处理的问题

- 默认开发端口已有其他服务，测试改用独立的 5187 端口，并禁止复用未知服务。
- 开发模式可能产生额外的初始查询，断网测试改为显式控制离线期间，避免依赖“仅第一次请求失败”的不稳定假设。
- 一次多浏览器并发启动超时，测试并发调整为 2；最终 13 项全部通过。
- 依赖下载及本地浏览器测试受到沙箱网络、端口权限限制，经工具权限流程后完成安装与验证。

## 五、尚未完成的产品闭环与限制

| 缺口 | 对用户的影响 | 当前前端处理 |
| --- | --- | --- |
| 缺少 multipart 文件任务接口 | 不能从网页提交论文并启动真实查新 | 默认关闭文件提交，明确提示服务尚未开放；仍允许本地预览 |
| 缺少真实节点进度 | 无法显示实际六阶段执行位置 | 显示排队/正在查新的不定长状态，不按时间模拟 |
| 缺少报告文件 HTTP 接口 | 不能下载后端 Renderer 生成的 Markdown | 展示已有结构化结果；不伪造下载文件 |
| 未提供 PDF Renderer | 无真实 PDF 报告可下载 | 不宣称可生成 PDF；本地 PDF 阅读能力可用 |
| 任务保存在后端进程内 | 服务重启后任务编号可能失效 | 404 明确说明，并允许用户重新开始 |
| SSE 未接入 | 当前依靠轮询更新状态 | 采用可退避、可取消的轮询请求层 |
| 文件限额尚未与后端统一 | 上线后的实际限制尚未确定 | 暂定单文件 30 MB、合计 100 MB、参考文献 20 个，集中配置 |
| 背景图依赖外部站点 | 图片加载受网络影响 | 深紫色回退，不影响操作；未将外部图片下载入库 |

当前文件 API 开关是构建配置，不是自动能力探测。后端接口实现并验证前，不应设置 `VITE_FILE_API_ENABLED=true`。

若提交请求超时或断网，客户端可能无法判断服务端是否已创建任务；前端会提示用户先确认结果，不自动重新创建。后续建议后端支持幂等创建或可查询的提交标识，以进一步避免人工重试造成重复任务。
