# 查新点覆盖与证据充分性修复：本地实施记录

## 已实现

- 固定 MF2033k6lC 输入并补齐有界作者贡献段，使 Sketch-DBH 在 PaperDigest 可见；提取对象契约一致，超额不截断，去重输入包含机制与来源，无效删除索引不生效。共享五次模型调用上限，一次有界补核查；数量不足生成警告和候选级旁路轨迹。
- Researcher 提示词加入关键未知触发全文、Reader 核验、失败保留未知与停止条件；未改变摘要优先及外部请求配置。
- Reviewer 单卡与汇总接入模板，并在所有路径应用“未提及不是不存在”的证据边界；工具权限、超时和引用校验保持。
- 检索规划保留核心机制；Coordinator 与报告绑定保护 Reviewer 的不足状态，逐点摘要不会把不足包装成已裁定。
