## 摘 要
由于现实世界中的大多数数据都可以用图表示，因此近年来针对图表示学习的研究越来越受到关注。通过将高维图数据转化成低维的表征向量，图表示学习可以有效地对图的信息进行存储并快捷地访问图中实体的关键知识。利用学习到的图表征数据可以为社交网络行为分析、节点分类、链路预测和聚类等下游任务提供帮助。随着深度学习的快速发展，研究人员提出了基于图神经网络的图表示学习方法，其使图中的节点能够同时学习图的结构信息以及邻域节点的特征信息，从而得到高质量的低维表征。针对图神经网络上的图表示学习，本文主要关注两个问题：大规模时序图场景下的图表示学习方法和分布式场景下的大规模图的图神经网络优化训练方法。
真实世界中的图数据规模往往十分庞大且处于动态变化的状态，而现有的图神经网络要么无法处理动态时序图上的图表征学习，要么面对大规模图数据集时训练效率低下。为了解决大规模动态图上的图表征学习问题，本文提出了一种基于图摘要的大规模时序图表示学习方法——GSAERU模型。GSAERU模型由“图表征学习模块”和“时序学习模块”两部分构成。首先将动态时序图建模为各时刻上原图快照的序列，接着在单时间步上将图快照输入图表征学习模块。该模块通过图摘要技术对原图进行压缩，并将压缩后的新图输入图自编码器，利用和原图的重构误差训练原图节点的表征。在获得单时间步上的图表征后将其输入时序学习模块，并通过一个循环神经网络学习原图在时间维度上的特征信息与依赖关系，从而得到大规模时序图的高质量表征。基于在四个真实世界的大规模图数据集上的大量实验表明，GSAERU 模型能够高效生成时序图的表征。与传统的图神经网络算法相比，其平均内存消耗和平均训练时长只有其 9.86% 与 13.27%，且与性能最好的算法在大部分指标下的差距都不超过3.5%。

使用分布式技术加速神经网络训练也是如今热门的研究课题，因为在处理大规模数据时，单个设备（如 CPU，GPU）有限的内存和计算资源往往会成为训练瓶颈。而分布式技术可以提供更多的计算资源来提高训练效率。然而由于图数据的不规则性，传统分布式机器学习方法中的子任务划分和模型训练方法难以直接应用于图神经网络。针对大规模图流数据场景下的分布式图神经网络训练优化问题，本文提出了基于图摘要的分布式图神经网络优化训练算法DSGNN 模型。DSGNN 模型采用“领导——工作者”工作模式，首先由领导节点利用一个基于边分割的图流划分算法对原图进行划分并将划分子图分配给各个工作节点。工作节点随后执行一个基于图摘要技术的小批量训练并将训练结果通过一个注意力层返回给领导节点，最后由领导节点汇总结果并计算梯度，并根据梯度同步更新所有计算节点上的模型。基于四个真实世界的大规模图数据集上的大量实验，结果表明 DSGNN 模型可以大大加速 GNN 模型的训练，并且在链路预测任务上的F1 分数显著高于其它分布式图神经网络模型。
关键词：图表示学习；深度学习；图神经网络；分布式技术

## Abstract
Since most data in the real world can be represented by graphs, research on graph representation learning has attracted increasing attention in recent years. By transforming high-dimensional graph data into low-dimensional vectors, graph representation learning can store graph information and access key information of the graph effectively. Utilizing the learned graph representation data can benefit downstream tasks such as social network, node classification and so on. With the development of deep learning, researchers have proposed a graph representation learning method based on graph neural network, which enables nodes in the graph to simultaneously learn the structural information of the graph and the feature information of neighboring nodes, thereby obtaining high-quality and low-dimensional representations. For graph representation learning on graph neural networks, this paper focuses on two issues: graph representation learning methods in large-scale sequential graphs and graph neural network optimization training methods for large-scale graphs in distributed scenarios.
The scale of graph in the real world is often large and keeps changing, and the existing GNN models are either unable to handle graph representation learning on dynamic sequential graphs, or the training efficiency is low on large-scale graph. To solve the problem of graph representation learning on large-scale dynamic graphs, this paper proposes a large-scale sequential graph representation learning method based on graph summarization—GSAERU model. The GSAERU model consists of two parts: ”graph representation learning module” and ”time sequence learning module”. First, the dynamic sequence graph is modeled as a sequence of snapshots of the original graph at each moment, and then the graph snapshots are input into the graph representation learning module at a single time step. This module compresses the original graph through

# Page 8
the graph summarization technology, and inputs the compressed new graph into the graph autoencoder, and uses the reconstruction error with the original graph to train the representation of the nodes of the original graph. After the graph representation on a single time step is obtained, it is input into the timing learning module, and the feature information and dependencies of the original graph in the time dimension are learned through a recurrent neural network, so as to obtain a high-quality representation of large-scale timing graphs. Extensive experiments on four real-world large-scale graph datasets show that the GSAERU model can efficiently generate representations oftiming graphs. Compared with the traditional graph neural network algorithm, its average memory consumption and average training time are only 9.86% and 13.27%, and the gap with the best performing algorithm in most indicators does not exceed 3.5%.
Using distributed technology to accelerate neural network training is also a hot research topic nowadays. The limited memory and computing resources of a single device often become a training bottleneck when processing large-scale data. Distributed technology can provide more computing resources to improve training efficiency. However, due to the irregularity of graph data, the subtask division and model training methods in traditional distributed machine learning methods are difficult to be directly applied to graph neural networks. Aiming at the optimization problem of distributed graph neural network training in large-scale graph streaming data scenarios, this paper proposes a distributed graph neural network optimization training algorithm based on graph summaries——DSGNN model. The DSGNN model adopts the ”leader-worker” mode. First, the leader divides the original graph using a graph flow partition algorithm based on edge segmentation and assigns the divided subgraphs to each worker. The workers perform a mini-batch training based on graph summarization technology and return the training results to the leader through an attention layer. Finally, the leader summarizes the results and calculates the gradient, and synchronously updates the models on all computing nodes according to the gradient. Based on extensive experiments on four real-world large-scale graph datasets, the results show that the DSGNN model can greatly accelerate the training of GNN models, and the F1 score on the link prediction task is significantly higher than other distributed graph neural network models.
keywords: graph representation learning,deep learning,graph neural network, distributed technology

## 第一章 绪论
## 1 . 1 研究背景
图是一种通过节点集合与边集合来描述数据中的实体对象及其抽象关联关系的数据结构，有着强大的非结构化数据的表示能力。因此图状数据有着相当广泛的应用，如社交网络中用户的关注关系，电子商务平台中用户与商品的推荐关系，金融领域中的账户汇款关系等，这些不仅与实际生活息息相关，也在各自领域发挥着重要的作用。随着大数据时代的到来，大量的数据以非结构化的形式涌现，截至 2022 年，全球社交媒体用户超过 46.2 亿，相当于全球总人口的 58.4%。其中 Facebook 的月活跃用户数达到 29.36 亿，微信月活跃用户达到 12.88 亿，YouTube 的潜在广告覆盖面为 24.76 亿，TikTok 广告每月覆盖 10.2亿成年人，这些平台每天都在产生着数以万亿计的用户内容与交互联系，高效地处理分析图数据能够帮助我们挖掘其中丰富的有价值信息，为研究与生产提供新的视角和工具。因此在 DB-Engines 统计的数据库流行趋势排名中，相比于关系数据库、文档数据库等常见数据分析工具，图数据库是自2013年以来增速最快的分类。依据国际知名调研机构 Gartner 的预测，全球图分析应用将以每年 100% 的速度迅猛增长，到 2025 年使用图技术进行数据分析和创新的比例将由 2021 年的 10% 提升至 80%，包括图数据库管理系统在内的图技术市场将增长到 32 亿美元，复合年增长率为 28.1% 。显而易见，对于大规模图数据的处理和分析已经成为下一个技术创新的前沿领域，亟需针对于图数据的有效分析手段。
针对这一问题，科研人员开发了各种图嵌入（Graph Embedding）技术来将原始图数据转换为统一维度的向量，这些向量中保存着原图的拓扑信息，可以用来为社交网络分析、节点分类、链接预测和聚类等下游任务提供重要支撑。这一过程也被称为图表示学习（Graph Representation Learning）。经典的图嵌入方法旨在将高维图数据的维度降低为低维表征，同时保留原图的拓扑信息。它们包括基于线性方法的主成分分析（Principal Component Analysis，PCA）[1]和基于非线性方法的等距特征映射 [2]，基于随机游走的方法 [3] 和基于矩阵分解的方法 [4]。虽然这些方法能学习到原图的拓扑信息，但却无法针对原图携带的特征信息进行学习。

近年来随着深度学习的普及，使用神经网络模型进行表示学习成为了研究热门，这是因为其能够从规则的数据结构中提取特征信息。然而非结构化的图数据有着不相互独立的节点, 每个节点拥有不同数量的连接关系, 传统神经网络中的一些重要操作无法直接应用到图数据，为了解决这一问题，图神经网络应运而生。
图神经网络（Graph Neural Networks，GNNs）是一种基于深度学习处理图数据的方法，它将图上的传播操作和神经网络结合起来，能够学习到图数据中的节点与图结构的内在规律和更加深层次的语义特征，弥补传统深度学习在可推理和可解释性的局限性。在实际应用中，基于图神经网络的图表示学习方法表现明显优于其它传统图表示学习方法 [5]。
尽管 GNN 模型在处理图数据上展现出了优秀的能力，但如何高效地大规模图数据上训练模型一直以来都困扰着科研人员。以训练 GCN 模型为例，一个节点的表征每次更新都需要递推式地依赖于其邻居节点的表征，这些节点表征之间的运算会随着图的规模以及 GNN 模型隐藏层数的增长呈指数级增长，这会导致过长的训练时间以及大量的内存消耗。GraphSage[6] 在一个 TeslaP100GPU 上需要花费数小时时间才能完成 Amazon 采购网络数据集（包含约二百万个节点）的训练 [7]。而 VRGCN[8] 在一个 Tesla V100GPU（16GB 内存）上训练同样的数据集甚至会出现内存溢出的问题 [9]。为了解决这一问题，科研人员分别引入了采样和分布式计算的方法。通过采样可以在原图上得到一张规模远小于原图的子图，利用采集得到的子图进行模型训练即可达到加速训练的目的，然而采样得到的子图会不可避免地丢失原图的拓扑信息从而使模型的精度下降。另一种方法是将分布式技术应用于图神经网络训练。然而由于图数据的不规律性，很难将传统的分布式机器学习方法直接应用在图神经网络上，需要根据图数据的特性重新设计分布式场景下的任务划分与模型训练模块。如何在分布式场景下高效训练大规模图的图神经网络是一个值得研究的问题。
到目前为止，大部分的 GNN 模型是针对不随时间变化的静态图开发的。然而现实世界中的真实图数据规模往往十分庞大且处于动态变化的状态，例如社交网络、金融交易网络和引文网络。针对动态时序图，如果仍然使用基于静态图的图神经网络算法学习其表征，往往会丢失其时间维度上的特征信息和依赖关系，使得学习到的表征质量不佳。为了解决这一问题，目前主流的解决方法是采用图神经网络与循环神经网络（Recurrent Neural Networks，RNNs）结合的架构，首先通过 GNN 模型学习图的表征，再输入 RNN 模型中进行时序特征的学习。然而，与 GNN 模型类似，RNN 模型也受到“大规模数据下训练成本过高”这一问题的困扰。在大规模动态时序图上直接应用这种架构学习图表征会进一步凸显这个问题。如何高效地在大规模时序图上进行图表示学习仍是一个值得思考的问题。

## 1 . 2 研究问题
本节中首先探讨了现有的基于图神经网络的图表示学习方法的局限，提出大规模时序图表示学习效率问题，并阐述解决该问题所面临的挑战。接着探讨了图神经网络在分布式场景下的训练难点，提出分布式图神经网络训练优化问题，包括数据分区和图计算优化，并阐述解决该问题面临的主要挑战。
## 1.2.1 大规模时序图表示学习的效率问题
在大规模时序图表示学习任务中，主流的解决方法是使用图神经网络与循环神经网络相结合的框架。首先利用图神经网络学习单时间步上的图表征，接着将这些表征输入循环神经网络中进行训练以学习其时间维度上的特征。然而，无论是图神经网络还是卷积神经网络的训练都涉及大量的矩阵乘积计算，当输入图的规模增大时，其训练时间也呈指数级增长，同时带来极大的计算资源消耗。此外，由于循环神经网络要求输入数据的规模保持不变，而在时序图场景中图中节点可能会产生增减，造成前后时间步之间数据规模的变化，使得循环神经网络无法正常训练。
在大规模时序图中进行图表示学习，同时解决模型训练效率问题，具有如下挑战：
• 如何对动态图进行建模，使得其能刻画图中节点与边随时间变化的动态过程。
• 如何在不过分损失模型精度的情况下尽可能缩短模型的训练时间和节约训练占用的计算资源。

## 1.2.2 分布式场景下的图神经网络训练问题
分布式图神经网络训练的工作流程一般分为三个阶段：1）数据划分；2）GNN 模型优化；3）梯度聚合。其中梯度聚合步骤的过程与传统分布式机器学习方法类似，而前两个过程由于图数据分布的不规律性，在实际实施过程中需要考虑负载均衡，通信开销等具体问题。因此如何在分布式场景下高效训练图神经网络模型具有如下挑战：
• 如何进行数据分区。数据分区是将输入数据（图和特征）分配到一组工作节点中。首先考虑到负载均衡问题，每个工作节点应当接收到规模均匀的子任务从而确保系统不会被某些节点拖慢整体训练速度，而图数据由于节点分布的不规律性，难以像传统数据一样直接进行划分。此外，GNN 模型训练时需要不断聚合目标节点的邻域信息，但在分布式场景中其邻域节点往往会出现本地缺失的现象。如果忽视了这部分缺失的节点，模型的准确性将会被破坏，如果需要获取目标节点的完整邻域信息，则需要向其它机器发送请求，造成大量的通信开销，从而降低分布式训练的效率。
• 如何进行本地 GNN 模型训练。由于数据的依赖性，工作节点进行本地模型训练的方式与传统的深度学习训练方法有很大不同。在不访问其他工作节点获取邻域信息的情况下，可能无法生成正确的计算图从而使得模型的精度下降。如果采取允许访问其他工作节点的模式，又会带来通信协议选择和隐藏层之间参数同步的问题。
## 1.3 主要贡献
## 1.3.1 基于图摘要的大规模时序图表示学习算法
本文对大规模时序图场景下的图表示学习进行了研究，在广泛调研现有方法并分析其优劣后，我们提出了一种基于图摘要的大规模时序图表示学习算法
GSAERU。GSAERU 模型包含”图表征学习“与”时序学习“两个模块，将每个时刻上动态图的快照输入到GSAERU模型中并生成多个图摘要，并将这些图摘要输入到对应的图自编码器中，利用编码器生成隐藏表征，然后使用解码器将这些表征解码得到原图的预测，并利用与原图的对比得到重构误差，利用此重构误差来训练从而增强隐藏表征的表达能力。在为每个时刻的图中节点都生成对应的表征后，将这些表征输入到一个循环神经网络中训练即可得到最终的同时包含图结构信息与时序信息的高质量表征。其主要贡献可以总结为以下三点：

• 提出了一种新的图表示学习模型——GSAERU，用于大规模时序图数据上的节点表征学习。现有的采用图神经网络与循环神经网络结合解决动态图问题的图表示学习算法，为了使 GNN 模型训练得到的表征可以满足循环神经网络的输入条件，往往需要固定图中的节点不发生增减变化，而GSAERU 模型通过引入图摘要技术将原图映射到固定规模的新图中，解决了GNN 模型输出无法直接输入到RNN 模型中进行训练的问题。
• 利用图摘要技术加速模型训练和减少模型占用的计算资源。GSAERU 模型对于输入的大规模图，首先利用图摘要技术从其中生成多个规模较小的”子图“，并在这些子图的基础上使用图自编码器学习其表征，并通过将这些图摘要生成的节点表征聚合得到原图的节点表征。由于图摘要技术生成的子图其规模远远小于原图，所以在这些子图上的训练成本也远低于原图，使训练大规模图的速度加快，内存消耗减少。
• 基于四个真实世界中的大规模时序图数据集进行了大量实验。与目前主流的动态图表示学习方法（DynamicTriad、MPNN-LSTM、EvolveGCN 和TGAT）相比，GSAERU 模型的训练速度更快，消耗内存更少，同时性能与目前最好的算法相比差距不超过3.5%。
## 1.3.2 基于图摘要的分布式图神经网络优化训练算法
本文也对分布式图神经网络算法进行了研究，基于充分调研现有分布式图神经网络训练框架的优势与缺陷，我们提出了一种基于图摘要的分布式小批量图神经网络训练框架——DSGNN。DSGNN 由一个领导节点和若干工作者节点构成，其中领导节点使用一个基于边分割的图流划分算法对输入数据进行预处理，其同时负责同步更新 GNN 模型参数。工作者节点则负责利用接收到的划分子图，结合基于图摘要的小批量样本学习方法进行模型的训练，并将结果返回给领导节点。其主要贡献可以总结为以下三点：
• 提出了一种新的基于图摘要的分布式图神经网络训练框架，称为 DSGNN，用于分布式场景下的基于图神经网络的图表示学习。与现有的独立采样分布式图神经网络训练框架不同，该模型可以在工作节点上对子图进行小批量样本的学习，而不是让领导节点完成子图生成。同时，使用图摘要技术产生的子图，其规模远远小于原图，在其基础上进行模型训练可以大大提升效率。

• 提出了一种新的基于边分割的图流划分算法——Sketch-DBH，用于处理大规模图流数据下的子图划分问题。该算法通过 Count-Min Sketch 这一概率数据结构存储每个节点的度数信息，并使用一个最小堆维护图流数据中的高频节点信息，使其可以在常数时间内返回查询结果并以此根据节点度数信息生成单条图流数据即将被分配到的子图编号。Sketch-DBH 算法可以高效完成大规模图流数据的划分且确保负载均衡，从而加速整个框架的模型训练速度。
• 基于四个真实世界中的大规模图数据集，我们首先使用提出的 DSGNN 框架实现了三个经典图神经网络模型的分布式版本，并比较集中式与分布式训练下模型性能的差异。实验结果表明，与集中式 GNN 模型训练相比，我们的分布式训练算法可以有效缩短训练时间和节约计算资源，且绝大部分情况下分布式与集中式训练的结果在 F1 值这一指标上相差不超过 1%。接着将提出的框架与三个主流的分布式图神经网络训练框架（ROC、DistDGL和 Aligraph）进行对比，比较其在相同数据集和 GNN 模型下的性能差异。结果表明 DSGNN 对分布式 GNN 模型训练的提升效果显著高于其它三种方法。最后我们通过数据可视化显示了在 DSGNN 框架下训练的 GNN 模型的鲁棒性。

## 第二章 相关工作
图神经网络一直是解决图表示学习问题的有效方法，在社交网络、生物医疗、交通规划等领域都取得了成功的应用。本章结合现有研究，将图神经网络分为三类：（1）基于静态图的方法；（2）基于动态图的方法；（3）基于分布式的方法。之后将按照分类对相关领域的研究进行文献综述。最后，本章将介绍一种针对大规模图数据的降维方法——图摘要。图摘要技术通过聚合，简化等方法在原图的基础上生成一个较小的摘要图，该摘要图能保存原图中的有效信息，从而大大减少存储代价并加快信息提取分析速度。
## 2.1 图神经网络
随着神经网络和深度学习技术的广泛应用，受到卷积神经网络和循环神经网络成功案例的启发，科研人员试图将神经网络技术推广到图这一领域中，并产出了许多优秀的成果。本节将目前最火热的图神经网络算法根据应用场景的不同总结为三类——基于静态图的方法、基于动态图的方法和基于分布式的方法。接下来将对这三类方法分别进行介绍和总结。
## 2.1.1 基于静态图的方法
针对静态图的图神经网络设计，研究人员通常使用图卷积、注意力机制和图采样等方法来让图中的节点学习图的拓扑信息以及其邻域的节点特征信息，从而获得高质量的表征向量。
目前，图卷积神经网络（Graph Convolutional Network，GCN）[10] 模型被普遍认为是进行图表示学习的有效方法。GCN 是一种端到端的半监督学习方法，适用于具有任意大小和形状的图结构数据。GCN 使用非欧几里得域中的图拉普拉斯算子 [11] 进行卷积运算并迭代聚合节点的邻居嵌入，以此模仿传统卷积神经网络中的卷积操作，从而使图表征学习到图拓扑信息和节点结构信息。

其中A为图的邻接矩阵， { \hat { A } } = A + I ，I为单位矩阵，D 为图的度矩阵。
此外，在 GCN 的基础之上，Derr 等人提出了带标签的图卷积神经网络（SGCN）[12]，通过节点附带的标签信息分别设置了正负标签的传播规则，从而解决了图中正负标签节点分布数量不平衡影响表征表达效果的问题。Kingma等人提出了基于 GCN 的变分图自编码器（VGAE）[13]，其采用“编码器-解码器”的结构，首先由作为编码器的 GCN 将输入数据映射到一个隐藏表示空间得到隐藏表征，接着利用解码器将隐藏表征还原到原图空间，通过最小化输入和输出的重构误差使得隐藏表征学习到原图的结构信息，从而得到高质量的节点表示。
另一种主流的方法是将注意力机制与图神经网络结合，利用注意力机制使得模型在图表示学习过程中更关注与训练任务更相关的图的部分。这种处理的优点在于可以降低图中“噪声”对训练结果的影响，从而增加信息处理中的信噪比 [14]。基于注意力机制的图神经网络旨在为目标节点 t 的邻域节点分配注意力权重 \alpha _ { i } \in [ 0 , 1 ] ，且其满足 \textstyle \sum _ { i \in N ( t ) } \alpha _ { i } = 1 ，N(t) 为节点 t 的一阶邻居集合。velivc 等人提出的图注意力网络（Graph Attention Network，GAT）[15] 使用隐藏的自我注意力层来学习节点表征，其目的是计算注意力系数：
$$
\alpha _ { i j } = \frac { e x p ( L e a k y R e L U ( a [ W h _ { i } | | W h _ { j } ] ) ) } { \sum _ { k \in N ( i ) } e x p ( L e a k y R e L U ( a [ W h _ { i } | | W h _ { k } ] ) ) }\tag{2 2}
$$
在 GAT 的基础之上，ABU 等人提出了基于图注意力机制的随机游走算法（AttentionWalks）[16]，其从目标节点开始采用随机游走策略采集邻域信息，并使用图注意力系数确定下一步将要访问的节点。XuQ 等人将注意力机制应用于图递归神经网络，使模型专注于保存更多相关语义信息的节点 [17]。它通过对连续 k 个相邻节点进行采样并生成子图以构建递归神经网络，并通过注意力系数来控制邻域信息传递到目标节点的权重。
尽管注意力机制已被证明可以用来提高某些图表示学习模型的性能，但它并不是总能提高图嵌入的准确性[18]。
除了采用图卷积和图注意力机制，科研人员还尝试了许多其它方法来学习图表征。Hamilton 等人提出了使用采样和聚合的方法归纳学习节点嵌入

（GraphSage）[19]。其训练了一组聚合函数，首先利用目标节点邻域节点的特征信息进行学习，之后将这些局部领域的特征分别聚合并传递给目标节点。Wang 等人提出了一种基于对抗生成训练的图表示学习算法（GraphGAN）[20]。其借鉴了生成对抗网络（GAN）的思想，为了拟合目标节点邻域的真实分布，GraphGAN 使用生成器对图中节点之间的连接概率进行建模，并生成虚拟节点，再使用鉴别器评估目标节点与其邻域节点之间有边的概率，以区分生成器生成的虚拟节点和真实存在的邻域节点。通过生成器和鉴别器之间的对抗提升图表征的鲁棒性。
## 2.1.2 基于动态图的方法
近几年来，针对时序图上的动态图表示学习问题引起了科研人员的兴趣。现有的针对时序图的表示学习方法大多是由静态图上的方法拓展而来。
一种流行的动态图表示学习方法是将动态图中节点和边随时间的变化建模为连续的点过程（stochastic processes）[21]。KnowEvolve[22] 和 DyRep[21] 将边随时间的增减建模为点过程函数，并使用神经网络将点过程函数参数化，从而对该边连接的节点嵌入进行更新。DynamicTriad[23] 使用点过程模拟动态图中更复杂的变化模式——三元闭包过程，其描述了图中具有三个节点的三元组从一对节点不连接的状态发展到任意节点两两连接的状态。模型基于所有的三元闭包过程学习图中节点的表示。HTNE[24] 同样对节点的点过程进行建模，另外加入了注意力机制来学习邻居节点对当前节点长期和短期的影响，最终根据该注意力系数更新目标节点表征。这类方法通过将动态图的随机变化过程建模为以时间为参数的连续点过程函数，使得模型能够有效生成动态图的表示并以此预测动态图的变化。
得益于循环神经网络（Recurrent Neural Networks，RNNs）的成功，另一种对动态图表示进行学习的方法是在图神经网络中引入 RNN 架构。TGN[25]和 JODIE[26] 仿照 LSTM 的结构为每个图节点维护一个记忆单元和隐藏单元，并通过节点随时间变化的情况更新这些单元，最后利用隐藏单元训练得到节点的表示。EvolveGCN[27] 提出使用 RNN 辅助训练 GCN 模型的参数。其将动态图建模为一个静态图序列，序列中的每张图代表其在对应时刻的图快照。接着构建一个标准 LSTM 模型，并将其中隐藏单元的全连接层替换为 GCN 模型的图卷积层，之后将这些静态图的邻接矩阵与特征矩阵输入 LSTM 模型，从而达到更新 RNN 隐藏状态的同时训练 GCN 模型的目的。尽管基于 RNN 的动态图表示学习方法可以有效保存和学习与时间维度相关的特征和事件并预测图的变化趋势，但由于 RNN 本就高昂的训练成本，结合 GNN 模型后需要进行大量的高维向量运算，会造成大量的内存占用，产生极大的计算成本。

## 2.1.3 基于分布式的方法
利用图神经网络进行图表示学习可以得到高质量的表示，但随着图规模的增大，其消耗的训练时间也急速增长。为了达到加速训练的目的，科研人员尝试将分布式技术与图神经网络结合，并产出了许多优秀的成果，目前主流的分布式图神经网络算法可以分为一下四类：
分布式全批量训练中分派子图方法：此类方法在每轮训练中对完整原图进行训练。首先将图数据和待训练的 GNN 模型输入领导节点，在训练过程中领导节点根据具体的节点特征聚合任务分发给各个工作者节点进行计算，然后收集返回结果并根据损失函数计算梯度，进行模型参数更新。NeuGraph[28] 通过将每个顶点的特征平均分成多个部分来探索特征级并行性，从而以更细粒度的方式划分工作负载。然后将其分配给不同的GPU线程进行相应的计算。该方法充分利用了 GPU 海量的并行计算资源。ROC[29] 将 GPU 内存管理转化为一个成本最小化问题，它使用递归动态规划算法寻找全局最优解来决定每一块数据应该缓存在哪个GPU内存中以供重用。然而，由于只有领导节点保存模型参数且训练时严重依赖于工作者节点的计算结果，导致这类方法的数据通信开销往往很大，且每轮训练的运行时间呈现不规律性。
分布式全批量预处理子图划分方法：此类方法也是在每轮训练中使用对完整原图进行训练，在得到输入的图数据和 GNN 模型后，增加了预处理阶段使领导节点将图提前进行划分，并将每个划分后的子图和一份 GNN 模型的副本发送给对应的工作者节点，由它们在本地进行 GNN 模型的训练，最后将结果返回领导节点，由领导节点汇总后再统一通知工作者节点更新模型参数。DGCL[30] 分布式 GNN 训练提供了一个通用且高效的通信库。它将最短路径生成树算法运用到传输规划中，通过“避免竞争”的策略提高链路使用效率并平衡不同链路上的工作负载。FlexGraph[31] 通过合并位于同一分区的相邻顶点的特征以减少数据传输量。当每个计算节点收到来自其他节点的邻居信息请求时，首先会在本地聚合部分邻居信息，然后将部分结果发送给请求计算节点，而不是直接发送初始邻居信息。请求计算节点只需要将接收到的部分结果与其本地节点进行聚合即可继续计算，这使得通信开销显著减少。然而，这类设计的好处是最大限度地调用了每个工作者节点的计算资源，缺点是在模型训练中工作者节点需要通过网络通信向其它节点获取其子图上待训练节点缺失的邻域信息，造成大量的通信开销。

# Page 27
分布式小批量独立采样方法：此类方法首先由领导节点对输入图数据进行采样，并将采样得到的子图和输入 GNN 模型的副本分别发送给工作者节点，由工作者节点在本地根据子图进行 GNN 模型训练。梯度计算和模型参数更新仍是由领导节点来完成。AGL[32] 提出了一种分布式管道，根据消息传递生成每个顶点的 k跳邻域，并使用 MapReduce 框架实现它。生成的 k跳邻域信息存储在分布式文件系统中。由于只需要在生成小批量样本时收集目标节点的 k 跳邻域信息，这样的设计大大加快了采样过程。SALIENT[33]通过使用CPU的多线程技术并行化小批量样本生成。它使用 C++ 的多线程技术端到端地实现小批量样本生成，从而提高了采样的性能。相较于前两类方法，本方法能够大大提升训练速度，但整体模型的运行效率仍由领导节点的采样效率来决定。
分布式小批量联合采样方法：此类方法中领导节点不再对原图采样，而仅仅只是划分原图，并将划分子图和 GNN 模型副本发送给工作者节点。之后由工作者节点在得到的划分子图上进行采样并将采样结果作为本地 GNN模型的输入进行模型训练。梯度计算和模型参数更新仍是由领导节点完成。AliGraph[34] 在其系统中实现了四种不同的图划分算法，其能适用于大部分类型的图数据输入。2PGraph[35] 提出了 GNN 层次感知缓存。它采用固定顺序对目标节点进行采样，这使得每个节点的训练顺序是固定的。通过在计算之前将所有目标顶点的k跳邻居预先缓存到GPU内存中，几乎可以完全消除数据传输的时间开销。这类方法的性能瓶颈在于领导节点的原图划分效率和工作者节点上的采样训练效率。
## 2.2 图摘要
图是一种现实世界中最常见的数据结构，包括社交网络、交通网络、计算机网络、电话呼叫或消息传递网络、位置签到网络、蛋白质-蛋白质相互作用网络、用户-产品评论或购买网络、功能或结构脑连接组等等。随着技术的进步，我们生成的数据量以及我们收集和存档此类数据的能力都在不断增加，大量生成的数据以及极快的数据产生速度对及时处理提出了挑战。图摘要技术作为解决大规模图存储与分析的有效手段，目前受到了越来越多研究人员的关注。图摘要算法以大规模的图作为输入，经过对结构信息和特征信息的提炼，输出一个小的摘要图，摘要图由超级节点和超边组成，富含原图中的特征信息 [36]。根据使用技术的不同可以将其分为以下三类——基于位压缩的方法、基于简化的方法和基于sketch的方法。下面将对其进行一一介绍并总结。

## 2.2.1 基于位压缩的方法
位压缩是数据挖掘中的常用技术。在图摘要算法中，这类方法的目标是最小化描述输入图所需的位数，其中图摘要由输入图及其未建模部分的模型组成。图摘要与模型的规模均远小于原图，且能表达原图的结构模式，如二分图。具体的处理方法有压缩和二次分组技术，这类方法通常将图摘要任务定义为一个模型选择任务，通过最小描述长度（Minimum Description Length，MDL）编码将原图G 和模型 M 转换为二进制位串，并通过最小化这两个二进制位串之间的距离来确定模型 M的类别：
$$
\underset { M } { \arg \operatorname* { m i n } } L ( G , M ) = L ( M ) + L ( G | M )\tag{2 3}
$$
其中 L(M) 为模型 M 的描述长度， L ( G | M ) 为给定模型下原图的描述长度。
Navlakha 等人 [37] 提出了一种基于有限误差的图摘要方法。其首先通过MDL 将节点聚合从而得到图摘要，并另外维护一个校正边集合。该方法生成的摘要图是一个聚合图，每个节点对应原图中的一组节点，并可以借助校正边集合查询到正确的原图结构。
## 2.2.2 基于简化的方法
基于简化的图摘要方法通过删除不太“重要”的节点或边来简化原始图，从而产生稀疏图。与生成“超图”的图摘要方法相反，此类方法生成的摘要图由原始节点与边的子集组成。
基于节点简化的摘要技术的代表性工作是 OntoVis[38]，用于简化大型异构社交网络。OntoVis 使用本体中与节点和边相关的信息（例如特定类型节点的度数）来语义修剪网络。其支持语义抽象、结构抽象和重要性过滤三种摘要生成方法。在语义抽象中，用户通过仅包括其类型从原始本体图中选择的节点来从原始图构造派生图。而结构抽象简化了图，同时保留了整个网络的基本结构。重要性过滤利用节点度等统计指标来评估节点类型之间的连通性和相

## 2 . 2 . 3 基于 sketch 的方法
sketch 是一个概率数据结构，可以高效地处理大规模数据的计数问题，其中最成功的应用为 Count-Min Sketch。如图 2 1所示，Count-Min Sketch 由 d 个哈希函数构成，其结构可以用矩阵表示，矩阵的每一行分别代表一个哈希函数。每个元素通过 d 个哈希函数映射到矩阵每一行中的一个单元格上。每当该元素的值更新时，通过哈希表查询每一行其存储的位置并将这些位置的值均加上更新值。在查询阶段，根据 d 个哈希查询到 d 个结果，并取其中的最小值作为结果返回，利用这种方法的查询精度为：
$$
P ( c _ { x } \le \hat { c } _ { x } \le c _ { x } + \varepsilon n ) \ge 1 - \delta\tag{2 4}
$$
其中 n 为数据流大小， c _ { x } 和 \hat { c } _ { x } 分别为真实值和预测值， \varepsilon 与 \delta 为自定义值，只需令Count-MinSketch的行数和列数分别等于 | { \frac { e } { \varepsilon } } | 和 \textstyle | \ln { \frac { 1 } { \delta } } | 上式即可成立。

## 3 . 1 研究动机
近年来，随着图表示学习（Graph Representation Learning）在社会科学、生物学、物理学等领域的问题上取得了一系列成就，图神经网络（GraphNeuralNetworks, GNNs）已成为了一个热门的研究课题。其主要通过深度学习技术学习非欧几里得数据——图的拓扑结构与特征信息，并为图中的节点与边生成对应的高质量表征，从而应用于链路预测、节点分类、图分类等下游任务。它在网络流量预测、金融风险评估、社交网络信息传播等现实领域有着广泛的应用前景。针对图表示学习的研究，科研人员已设计了许多经典且有效的图神经网络结构[6, 10, 15]。然而在实际应用中还存着两个巨大的挑战。
第一，到目前为止，大部分的 GNN 模型是针对不随时间变化的静态图开发的。然而，现实世界中的很多图是随时间的推移而动态变化的，例如社交网络、金融交易网络和引文网络。图3 1展示了一个用户与博文互动并相互关注的动态网络，其中的每条边都有一个时间戳，这些动态行为传达了重要的信息，可以挖掘出用户在时间维度上的依赖关系，帮助我们更好地预测用户未来的行为。但如果只考虑静态图，这些信息就会丢失。
第二，尽管 GNN 模型在处理图数据上展现出了优秀的能力，但如何高效地大规模图数据上训练模型一直以来都困扰着科研人员。以训练 GCN 模型为例，一个节点的表征每次更新都需要递推式地依赖于其邻居节点的表征，这些节点表征之间的运算会随着图的规模以及 GNN 模型隐藏层数的增长呈指数级增长，这会导致过长的训练时间以及大量的内存消耗。GraphSage[6] 在一个TeslaP100GPU上需要花费数小时时间才能完成Amazon采购网络数据集（包含约二百万个节点）的训练 [7]。而 VRGCN[8] 在一个 Tesla V100GPU（16GB 内存）上训练同样的数据集甚至会出现内存溢出的问题 [9]。
针对第一个挑战，研究人员尝试将时间维度上的特征更新纳入模型中从而将静态图方法扩展为时序图方法。DANE[40] 基于矩阵分解的方法，利用图拉普拉斯矩阵的特征向量计算图节点的嵌入，并根据矩阵随时间的变化动态地更新特征。然而这类基于矩阵分解的算法只关注了图中的结构拓扑信息，无法将节点的特征信息纳入考量。HTNE[24] 将图中边随时间的变化建模为一个连续的点过程，并使用注意力机制来衡量历史邻居对节点当前邻居的影响，最后利用神经网络进行训练。然而这类方法只关注了时序图中边的变化情况，忽视了节点特征也会随时间变化的问题。随着循环神经网络（Recurrent NeuralNetworks, RNNs）的兴起，使用 GNN 与 RNN 相结合的架构成了目前研究时序图问题的主流方法。如图3 2所示，这类方法使用 GCN 或 GAT 获取节点嵌入，然后将其输入到学习时序性的 RNN 模型中，这样就能获得兼顾图信息与时序信息的表征，GCRN[41] 和 TGAT[42] 是其中的代表方法。然而为了保证RNN 模型训练的性能，这类方法往往需求时序图中的节点不会发生变化，即每个节点在每个时间步上都必须出现。同时由于 RNN 的训练也非常耗时，因此图的规模成为了制约此类模型训练的瓶颈。

## 3 . 3 . 1 模型框架

## 3 . 3 . 2 . 1 图摘要生成
第2.2.3节中我们介绍了基于 sketch 的图摘要技术的背景知识，本节将主要介绍 GSAERU 模型如何为时序图中一个时刻的快照 \mathcal { G } ^ { t } 生成对应的图摘要： \mathcal G S ^ { t }

## 3 . 3 . 2 . 2 图自编码器
在上一节中，我们针对时序图 \mathcal { G } 在时刻 t 的快照 \mathcal { G } ^ { t } 生成了 k 个图 Sketch： \{ \mathcal { G S } _ { 1 } ^ { t } , \mathcal { G S } _ { 2 } ^ { t } , . . . , \mathcal { G S } _ { k } ^ { t } \} ，并通过在这些图 Sketch 上的联合查询可以以高准确度来还原原图。这表明可以通过学习这些图 Sketch 上的结构和特征信息得到表征，再通过聚合这些图 Sketch 的表征得到包含正确图结构信息的原图上节点的高质量表征。故本节我们采用图自编码器（Graph Auto-Encoder，GAE）来学习这些图 Sketch 上节点的表征。图自编码器是一种学习图节点表征的无监督神经网络模型，它由一个编码器和一个解码器构成，通过编码器将输入数据“压缩”为低维特征，再通过解码器将这低维特征重新还原为原始数据。通过最小化这一重构误差使得解码器的输出尽可能近似输入数据，从而使得模型能够学习到输入数据的隐藏特征。

## 4 . 1 研究动机
在深度学习领域，图神经网络（Graph Neural Networks，GNNs ）被认为是处理图数据学习任务的有效方法，它可以将图结构信息融入到深度学习中，从而取得明显优于传统数据挖掘方法和机器学习的效果。如今 GNNs 已被应用于现实世界中的许多领域，如社交网络分析 [60, 61]，生物医学中的蛋白质结构分析 [62]，购物网站商品推荐 [63–66] 和自然语言处理 [67, 68]。近年来，研究人员致力于 GNN 模型的设计，开发了包括 GCN[10]、GAT[15]、GraphSaint[7] 等一系列流行的图神经网络模型。同时，为了提高 GNN 模型开发效率，许多深度学习库提供了 GNN 开发的框架 [69–72]。另一方面，为了达到加速训练的目的，研究人员针对 GNN 训练的优化提出了一系列新方法，包括新的 GNN 运算内核（Computation Core）[73, 74]，用于加速图数据计算的编程模型 [75, 76]。然而，这些优化仅仅局限于在单个机器上训练 GNN，没有考虑到模型的可扩展性。
如今，真实世界中的网络图规模往往会非常巨大，以社交网络图（微博，微信）为例，其中包括上亿个顶点以及数十亿条边，而现有的大多数 GNN 模型无法处理大规模图数据集 [77] 或效率低下。因此，如何提高图神经网络模型在大规模图数据集上的训练性能对科研人员提出了新的挑战 [78, 79]。一种较为流行的解决方法是对原图使用采样 [7, 9, 80] 或蒸馏 [81–83] 技术得到一个规模远小于原图的“子图”，并以子图作为 GNN 模型的输入进行训练。这种做法虽然能大大提高训练速度，但模型性能最后会取决于所采集到的子图的质量，且由于子图会不可避免地丢失原图的结构信息，所以一定会导致模型预测准确度的降低。另一种方法是将分布式计算与 GNN 模型结合，因为在处理大规模图数据时，单个机器的内存和计算资源是有限的，往往会成为限制训练速度的瓶颈，而通过分布式计算能够调度更多的计算资源（如多 GPU 集群）来提高训练效率。图4 1展示了分布式 GNN 训练的通用框架，其中包含了一个领导节点和若干工作者节点。对于输入的大规模图，首先由领导节点将图学习任务划分为一个个子任务，并将这些任务分配给工作者节点进行模型训练，工作者节点完成运算后将结果返回给领导节点，并由领导节点汇总结果并统一更新模型参数。

更具体的，如图4 2所示，根据 [84] 提出的分类标准，我们将现有的分布式GNN 框架分为四类，下面我们对其运行过程进行一一介绍。
• 分布式全批量训练中分派子图方法：此类方法在每轮训练中对完整原图进行训练。首先将图数据和待训练的 GNN 模型输入领导节点，在训练过程中领导节点根据具体的节点特征聚合任务分发给各个工作者节点进行计算，然后收集返回结果并根据损失函数计算梯度，进行模型参数更新。其中的代表工作为NeuGraph[28]，ROC[29]。然而，由于只有领导节点保存模型参数且训练时严重依赖于工作者节点的计算结果，导致这类方法的数据通信开销往往很大，且每轮训练的运行时间呈现不规律性。
• 分布式全批量预处理子图划分方法：此类方法也是在每轮训练中使用对完整原图进行训练，在得到输入的图数据和 GNN 模型后，增加了预处理阶段使领导节点将图提前进行划分，并将每个划分后的子图和一份 GNN 模型的副本发送给对应的工作者节点，由它们在本地进行 GNN 模型的训练，最后将结果返回领导节点，由领导节点汇总后再统一通知工作者节点更新模型参数。其中的代表工作为 DistGNN[85]，FlexGraph[31] 和 SAR[86]。这类设计的好处是最大限度地调用了每个工作者节点的计算资源，缺点是在模型训练中工作者节点需要通过网络通信向其它节点获取其子图上待训练节点缺失的邻域信息，造成大量的通信开销。

• 分布式小批量独立采样方法：此类方法首先由领导节点对输入图数据进行采样，并将采样得到的子图和输入 GNN 模型的副本分别发送给工作者节点，由工作者节点在本地根据子图进行 GNN 模型训练。梯度计算和模型参数更新仍是由领导节点来完成。其中的代表工作为 AGL[32]，SALIENT[33]。相较于前两类方法，本方法能够大大提升训练速度，但整体模型的运行效率仍由领导节点的采样效率来决定。

## 4 . 3 . 2 基于 Sketch-DBH 算法的子图划分
子图划分是将一个大规模图均匀地划分为一系列子图去适应分布式场景，划分后的子图被下发给各个工作者节点进行并行执行。如果当前子图需要其它子图的信息，需要通过网络拓扑向其它节点发送查询请求，产生通信开销。因此子图划分的质量影响着每个节点的工作负载和工作者节点之间的通信开销。目前主流的子图划分模式分为离线模式和流模式 [88]。离线模式是将完整图数据一次性载入内存后再进行划分，而流模式是按批次读取图数据并实时地将节点和边分配到其对应的子图中。对于大规模图数据而言，由于机器内存难以存储完整原图，故使用流模式分割更为适合。

## 4 . 3 . 2 . 3 分配子图

在 DSGNN 框架每轮训练中，领导节点依据来自 K 个不同的工作者节点返回的损失函数值来更新模型参数。首先计算全局损失函数 l _ { g l o b a l }
$$
\begin{array} { l } { { l _ { g l o b a l } = \Gamma ( l _ { 1 } , l _ { 2 } , \dots , l _ { \mathcal { K } } ) } } \\ { { \ } } \\ { { \displaystyle = \frac { 1 } { \mathcal { K } } ( l _ { 1 } + l _ { 2 } + \dots \cdot + l _ { \mathcal { K } } ) + \lambda R ( w ) } } \end{array}\tag{4 5}

其中R(w) 为正则项，λ为正则系数。

## 4 . 4 . 1 . 4 评估指标

• 精确率（Precision，P）：正确判断为真的样本数占总的判断为真的样本数的比值。
• 召回率（Recall，R）：正确判断为真的样本数占总的总的真实真样本数的比值。
• F1 分数（F1 Score）：精确率与召回率的调和平均数，用于综合衡量一个分类模型的精确度。

## 4 . 5 本章小结
在本章节中，我们提出了一种基于图摘要小批量训练的分布式图神经网络训练框架。我们从图神经网络模型的”节点递归地聚合其邻域节点的信息“这一原理出发，通过图摘要技术中的局部敏感哈希算法将大规模图”压缩“为一张张小图，并基于这些子图进行小批量样本的训练模型，从而达到在分布式场景中加速 GNN 模型训练的效果。我们基于三个当下最热门的单机 GNN 模型，借助我们设计的框架实现其分布式训练版本，并在四个真实世界的数据集上对效果进行验证。实验表明，我们提出的分布式图神经网络训练框架能够大幅度加速模型的训练，同时有效节省计算资源。

## 第五章 总结与展望
## 5.1 工作总结
本文着力于目前图表征学习领域存在的两大问题——“大规模图数据训练耗时耗资源”与“传统方法难以训练动态图”。本文首先概述了图表示学习领域的相关背景知识，随后对待研究的问题进行了介绍，并对目前针对大规模动态图表示学习的研究工作和算法进行了整理。基于对当前研究工作中的优势与缺陷的分析，我们设计了两种算法——“基于图摘要的大规模时序图表示学习算法”与“基于图摘要的分布式图神经网络训练优化方法”。通过在多个真实世界的大规模动态图数据集上进行了大量实验，我们验证了算法在加速模型训练和减少计算资源损耗上的有效性。
对于“大规模图数据难以训练”的问题，本文首先调研了相关的解决方法，发现现有的解决方法主要围绕两个方面展开：第一，使用采样技术从大规模图中采集出一个规模远小于原图的子图并在其上进行模型训练，达到加速的目的；第二，使用分布式技术，通过增加计算节点的数量来加快训练速度。然而现有方法仍存在一些缺陷。对于采样方法，采样出的子图可能会丢失大量原图的拓扑信息从而导致模型性能的降低，以及采样生成子图的过程是否可以在线性时间内完成。对于分布式方法，分布在不同机器上的邻居节点想要获取对方信息需要发起请求，过多的通信开销会给系统带来极大的负担从而拖慢训练的速度。因此我们分别提出了基于图摘要的大规模时序图表征学习算法和分布式图神经网络训练加速算法，通过图摘要技术中的局部敏感哈希对原图中的节点进行映射从而得到一组规模远小于原图的图摘要。并通过在这些图摘要中使用时序学习方法与分布式技术达到加速模型训练和减少计算资源消耗的目的。通过在多个真实世界中的大规模图数据集上进行的实验显示了该方法的有效性。
对于“传统图表示学习方法难以学习动态图”的问题，本文首先调研了动态图表示学习的相关工作，发现现有的方法大多使用图神经网络与循环神经网络相结合的方式来学习动态图的表示，随后我们总结了这类方法的通用框架。

# Page 72
然而在实际应用中，由于循环神经网络的结构特殊性，其要求图中节点不能出现增减的变化，这就对动态图中节点增减这一情景做出了限制。因此我们提出了基于图摘要的动态图表示学习方法，其将原图节点通过一个局部敏感哈希映射到一个规模固定的新图中并学习新图的表示，最后将新图的表示作为循环神经网络的输入进行时序特征的学习，解决了现有方法无法处理动态图中节点变化的问题。大量基于真实世界大规模图数据集上的实验表明，本算法可以有效处理动态图中的时序信息。
## 5 . 2 前景展望
近年来图表示学习在现实中的多个领域都已取得了引人注目的成绩，包括金融、生物医学、社交网络，成为了解决链路预测、节点分类问题的有效方法。然而，随着所研究图的规模日益增大，面对动辄数百万节点与上千万条边组成的大规模图，传统的图表示学习方法往往不能有效对其进行训练，而引入采样等技术对原图进行“压缩”后训练的方法又会不可避免地丢失原图拓扑信息，从而使模型的精度下降。如何找到“效率”与“精度”之间的平衡点仍然是一个值得研究的问题。
尽管针对图表示学习已经提出了许多有效的方法，但如何提高所学习到表征的可解释性，即“如何判断训练得到的表征中每一维度特征所包含的具体信息”仍然是一项具有挑战性的任务。
此外，本文的研究只针对图中节点级的表示学习，而没有对边级别的表征乃至图级别的表征进行探索。在未来的研究中，将表示学习的范围扩大到针对边乃至子图可能是一个可行的研究方向。
