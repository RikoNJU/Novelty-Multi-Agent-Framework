# 已知问题与结论边界

1. L1 的 NP-1 原 Reviewer 为 `insufficient_evidence`，原因为 `technical_error`；报告只继承该状态，未修复 Reviewer。
2. 历史 Springer HTTP 404 及未执行方向不能写成零命中。
3. 原 Reviewer 关于“未提及／不采用／相矛盾”的语义风险未重新裁定；权威字段保真不等于结论正确。
4. 前端阶段业务详情接口仍为独立问题。本轮浏览器使用 API 拦截读取离线 Renderer 产物，没有验证生产恢复读取接口。
5. 原历史完整运行仍失败；两份来源都不是新端到端运行。真实模型报告节点未获本轮预算许可前，其完成率、耗时和实际费用未知。
6. 原 Runtime 的 `finish_reason` 缺失；本轮对历史截断的判断依据是末尾残缺和 usage 迹象，新记录器已补保存该字段。
7. 原完整性门禁在一般 Workflow 中仍为非阻断路径；报告节点回放脚本在门禁失败时停止持久化。新组装路径已防止已测试的覆盖和作用域错误，但一般 Workflow 门禁行为是后续独立改造点。
