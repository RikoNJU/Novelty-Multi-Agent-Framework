Contemporary CI/CD practices typically address vulnerability prevention and intrusion mitigation as disjoint activities, which may result in residual risk even after container images pass pre-deployment checks. Pre-deployment scanners can overlook vulnerabilities obscured by image layering or insufficient metadata, whereas runtime detection mechanisms commonly rely on single-source observations and thus fail to capture multi-step exploit chains. This work presents Janus , a coordinated framework for containerized CI/CD security across the pre- and post-deployment phases. Its key idea is that vulnerabilities should be handled according to when they can be addressed most effectively: Janus uses a policy gate to decide which vulnerabilities must be remediated before release and which residual vulnerabilities are explicitly deferred to runtime monitoring. To support pre-deployment decisions under CI/CD time budgets, Janus performs layer-aware incremental scanning and policy-controlled constrained patching on changed image layers. To protect against residual risk after deployment, it enforces the deferred set using abstract, stateful exploit-chain signatures that correlate system and network events through shallow-to-deep runtime inspection. Our evaluation on 346 container images (including all 146 official and 200 widely used community images) shows that Janus improves vulnerability coverage by 42.4% relative to representative scanners in our setup (e.g., Grype, Trivy, CVE-Bin-Tool) while reducing analysis latency by 79.6%. Moreover, on our tested exploit chains, Janus detects all chains that elude representative single-source IDS baselines. These results demonstrate the benefits of coordinating prevention and mitigation across the container lifecycle.
