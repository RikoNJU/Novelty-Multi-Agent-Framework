For deep learning-based object identification systems to be more accurate and efficient, feature selection is essential. High-dimensional feature spaces frequently contain redundant or unnecessary data, which raises the danger of overfitting and increases computational expense. In this work, we compare two widely used nature-inspired metaheuristic algorithms for feature reduction in deep learning pipelines: Particle Swarm Optimization (PSO) and Grey Wolf Optimizer (GWO). In order to find an ideal subset of features that maximizes classification performance while minimizing dimensionality, the suggested method combines a pre-trained convolutional neural network (CNN) for feature extraction, PSO, and GWO. Benchmark image datasets are used for extensive experimentation, and the accuracy, F1-score, computational complexity, and convergence behavior of the findings are assessed. Both PSO and GWO considerably reduce the feature set size without compromising model performance, according to our findings, with PSO exhibiting higher robustness and faster convergence in high-dimensional search spaces. This work proposes a scalable approach for real-world object recognition problems and sheds light on the practical trade-offs of swarm intelligence-based optimizers for feature selection.
