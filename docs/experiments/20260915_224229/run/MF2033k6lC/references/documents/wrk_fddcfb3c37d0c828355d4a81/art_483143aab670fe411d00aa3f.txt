Dynamic resource allocation represents one of the core benefits of server virtualisation. Within a cloud computing context, a user issues an infrastructure request, which is satisfied by spawning one or several virtual machines (VMs). We argue that tearing down VMs once the initial request completes can prove sub-optimal. Indeed, this implies that for every new infrastructure request, the VM creation procedure is applied and, therefore, incurs the VM creation overhead. In this reseach, we consider workload placement as the first response to an infrastructure request, followed by a VM placement when no running VM has the capacity to execute the workload. Our solution proposes a multi-heuristic approach to workload placement in VMs. First, we employ a compound scoring function in the vector bin packing (VBP) algorithm to optimally assign workloads to running VMs. Next, the remaining workloads are placed on available VMs using a beam search (BS)-flavoured ant colony optimisation (ACO). We present an empirical evaluation with varied configurations to demonstrate that coupling VBP and ACO enhances the placement quality.
