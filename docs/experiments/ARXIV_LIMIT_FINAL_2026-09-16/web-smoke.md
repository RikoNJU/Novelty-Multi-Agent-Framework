# Web smoke

每档串行执行同一组 8 个公开英文主题，按 8 → 6 → 4 → 2 秒顺序执行。各档独立进程，档间等待 8 秒。

| 配置间隔(s) | 返回候选 | 故障 | 重试 | 最小实际间隔(ms) | 查询累计耗时(s) |
|---|---|---|---|---|---|
| 8 | 8/8 | 0 | 0 | 8000.1 | 57.29 |
| 6 | 8/8 | 0 | 0 | 6000.1 | 59.71 |
| 4 | 8/8 | 0 | 0 | 4000.1 | 29.97 |
| 2 | 8/8 | 0 | 0 | 2008.3 | 25.31 |

共 32 次主题检索，32 次 HTTP 200，每次返回 5 个 SearchHit；网络错误被错记为 EMPTY 的次数为 0（真实运行未发生网络错误，分类故障路径另外以离线测试验证）。每个实际请求均写入现有 Runtime Debug。

默认保持 **8 秒**。2 秒小样本没有失败，但查询顺序固定、重复查询可能使后续档位命中缓存，不能把本实验视为长期容量证明或无偏性能比较。不存在自动切换 transport。

[汇总指标](metrics/web.json)，各档完整事件见 metrics/web-{8,6,4,2}.json。
