# Reviewer 证据边界核对

## 机制观察

- **A0/A1 权限**：2PS 与 WStream 的原摘要白名单都拒绝同 Work 正文；新目录经 Manifest 和文件哈希验证后允许各自正文。2PS 正文 `art_ebc47b0e70f5b363f3d871f2`、WStream 正文 `art_239d9f203a9c73612f1cbbaa` 均完成固定 128 字符读取。跨 Work 和不存在的 Artifact 继续拒绝。摘要 EOF 返回 `artifact_eof` 与空文本，不计作有内容的读取。
- **G0/G1 影子**：固定上一轮原始模型输出（2PS `llm_0069`、WStream `llm_0071`），旧守卫均从 `reviewed` 改为 `insufficient_evidence`；新路径的结构校验保留原始状态与相关性理由，旧规则只记录命中和将发生的改写。这个对照仅证明规则影响，**不证明两份旧裁定正确**。尤其 2PS 原始理由从“摘要未提及”推断全文技术差异，仍缺正文语义核验。
- **P0/P1 传递**：使用标记为合成语义判断的单卡输出，以及真实 2PS 正文读取字节。旧输入没有新证据 ID；新路径从 `read_id` 登记 180 字符准确摘录，引用可在单卡和汇总载荷中解析，原 Card/Evidence ID 列表未改。Renderer 能定位新 ID、Artifact 与范围。此测试证明数据流，不评价 Count-Min Sketch 等技术关系。
- **Debug/导出**：脚本模型和本地 Reader 走生产 Reviewer 链，导出包内含 Reviewer 输入、正式输出、旧守卫影子、读入材料和原文文件；独立导出位置的材料字节与原件一致。

## 效果与限制

本轮模型调用、外部获取和费用均为 0。L0/L1 Reviewer-only 语义效果对照尚未运行，因本轮未设具体新增付费上限。无法断言 Reviewer 已识别跨术语机制重合，也不能把 G1 保留的旧模型裁定当作正确标签。已有正文可读、证据可追溯、汇总与报告不断链；语义判断仍需固定 NP-3 成对输入的实际新模型决策验证。前端页面未启动，本地验证覆盖权威报告对象和 Markdown 渲染。
