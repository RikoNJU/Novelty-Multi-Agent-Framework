Abstract

The sheer increase in the size of graph data has created
a lot of interest into developing efficient distributed graph processing frameworks.
Popular existing frameworks such as GraphLab and Pregel rely on balanced graph partitioning in order to minimize communication
and achieve work balance.

In this work we contribute to the recent research line
of streaming graph partitioning [Sta14, SK12, TGRV14]
which computes an approximately balanced kk-partitioning of the vertex set of a graph using
a single pass over the graph stream using degree-based criteria.
This graph partitioning framework is well tailored to processing large-scale and dynamic graphs.
In this work we introduce the use of higher length walks for streaming graph partitioning
and show that their use incurs a minor computational cost which can significantly
improve the quality of the graph partition.
We perform an average case analysis of our algorithm using
the planted partition model [CK01, McS01].
We complement the recent results of Stanton [Sta14] by showing that
our proposed method recovers the true partition with high probability even when the
gap of the model tends to zero as the size of the graph grows. Furthermore, among the wide
number of choices for the length of the walks we show that the proposed length is optimal.
Finally, we conduct experiments which verify the value of the proposed method.

1 Introduction

The size of graph data that are required to be processed nowadays is massive.
For instance, the Web graph amounts to at least one trillion of links [goo]
and Facebook in 2012 reported more than 1 billion of users
and 140 billion of friend connections.
Furthermore, graphs of significantly greater size emerge by post-processing various other
data such as image and text datasets.
This sheer increase in the size of graphs has created a lot of interest
in developing distributed graph processing systems [KTF09, LGK+10, MAB+10],
in which the graph is distributed across multiple machines.
A key problem towards enabling efficient graph computations in such systems is the 𝐍𝐏\mathbf{NP}-hard problem of
balanced graph partitioning. High-quality partitions ensure low volume of communication and work balance.

Recently, Stanton and Kliot [SK12] introduced a streaming graph partitioning model.
This line of research despite being recent and lacking theoretical understanding
has already attracted a lot of interest.
Several existing systems have incorporated this model such as PowerGraph [GLG+12].
The framework of Fennel has been adapted by PowerLyra [CSC+13],
which has been included into the most recent GraphLab version
[bic, LGK+10] yielding significant speedups for various iterative computations.
Stanton performed an average case analysis of two streaming algorithms,
and explained their efficiency despite the pessimistic worst case analysis [Sta14].
Despite the fact that existing established heuristics such as Metis typically outperform streaming algorithms, the latter are well tailored to today’s needs
for processing dynamic graphs and big graph data which do not fit in the main memory.
They are computationally cheap and provide partitions of comparable quality.
For instance, Fennel on the Twitter network with more than 1.4 billion edges performed
comparably well with Metis for a wide variety of settings, requiring 40 minutes
of running time, whereas Metis 812\frac{1}{2} hours.

So far, the work on streaming graph partitioning is based on computing the degrees
of incoming vertices towards each of the kk available machines. Equivalently,
this can be seen as performing a one step random walk from the incoming vertex.
A natural idea which is used extensively in the literature of graph
partitioning [LS90, ST08, ZW04]
is the use of higher length walks. In this work we introduce this idea
in the setting of streaming graph partitioning.
At the same time we maintain the time efficiency of streaming graph partitioning
algorithms which make them attractive to various
graph processing systems [GLG+12, KTF09, LGK+10, MAB+10].

2.1 Existing Work

Balanced graph partitioning. The balanced graph partitioning problem is a classic 𝐍𝐏\mathbf{NP}-hard problem
of fundamental importance to parallel and distributed computing.
The input to this problem is an undirected graph G⁡(V,E)G(V,E) and an integer k∈ℤ+k\in\mathbb{Z}^{+}, the
output is a partition of the vertex set in kk balanced sets such that the number of edges across the clusters
is minimized. We refer to the kk sets as clusters or machines interchangeably.
Formally, the balance constraint is defined by the imbalance parameter ν\nu.
Specifically, the (k,ν)(k,\nu)-balanced graph partitioning
asks to divide the vertices of a graph in kk clusters each of size
at most ν​nk\nu\frac{n}{k}, where nn is the number of vertices in GG.
The case k=2,ν=1k=2,\nu=1 is equivalent to the 𝐍𝐏\mathbf{NP}-hard minimum bisection problem.
Several approximation algorithms, e.g., [FK02],
and heuristics, e.g., [KL70], exist for this problem.
When ν=1+ϵ\nu=1+\epsilon for any desired but fixed ϵ>0\epsilon>0 there exists a
O⁡(ϵ−2​log1.5​n)O(\epsilon^{-2}\log^{1.5}{n}) approximation algorithm [KR04].
When ν=2\nu=2 there exists an O⁡(log⁡k​log⁡n)O(\sqrt{\log{k}\log{n}}) approximation algorithm
based on semidefinite programming (SDP) [KNS09].
Due to the practical importance of kk-partitioning there exist several heuristics,
among which Metis [SKK00] stands out for its good performance.
Survey [BMS+] summarizes many popular existing methods for the balanced
graph partitioning problem.

Streaming balanced graph partitioning.
Despite the large amount of work on the balanced graph partitioning problem, neither state-of-the-art
approximation algorithms nor heuristics such as Metis are well tailored to the computational restrictions
that the size of today’s graphs impose.

Stanton and Kliot introduced the streaming balanced graph partitioning problem,
where the graph arrives in the stream and decisions about the partition need to be taken with on the fly quickly [SK12].
Specifically, the vertices of the graph arrive in a stream with the set of edges incident to them.
When a vertex arrives, a partitioner decides where to place the vertex “on the fly”, using limited computational
resources (time and space).
A vertex is never relocated after it becomes assigned to one of the kk machines.

In [TGRV14] well-performing decision strategies for the partitioner were introduced
inspired by a generalization of optimal quasi-cliques [TBG+13]
to kk-partitioning.
Both [SK12] and [TGRV14] can be adapted to edge streams.
Nishimura and Ugander [NU13] consider a realistic variation
of the original problem where the constraint of a single pass over the graph stream
is relaxed to allowing multiple passes.
Stanton showed that streaming graph partitioning algorithms with a single pass
under an adversarial stream order cannot approximate the optimal cut size within
o⁡(n)o(n). The same claim holds also for random stream orders [Sta14].
Finally, Stanton [Sta14] analyzes two variants of well performing algorithms
from [SK12] on random graphs. Specifically, Stanton proves that if the graph
GG is sampled according to the planted partition model, then the two algorithms
despite their similarity can perform differently and that
one of the two can recover the true partition whp, assuming that
inter-, intra-cluster edge probabilities are constant, and their gap is a large constant.

Planted partition model. Jerrum and Sorkin [Jer98] studied the planted bisection model,
a random undirected graph with an even number
of vertices. According to this model, each half of the vertices is assigned to one of two
clusters. Then, the probability of an edge (i,j)(i,j) is pp if i,ji,j have the same
color, otherwise q<pq<p. We will refer to p,qp,q as the intra- and inter-cluster probabilities.
Their difference p−qp-q will be referred to as the gap of the model.
Condon and Karp [CK01] studied the generalization of the planted bisection problem where instead
of having only two clusters, there exist kk clusters of equal size.
The probability of an edge is the same as in the planted bisection problem.
They show that the hidden partition can be recovered whp if the gap satisfies p−q≥n−1/2+ϵp-q\geq n^{-1/2+\epsilon}.
McSherry [McS01] presents a spectral algorithm that recovers the hidden partition
in a random graph whp if p−q=Ω(n−1/2+ϵ)p-q=\Omega(n^{-1/2+\epsilon}). Recently, Van Vu gave an alternative
algorithm [Vu14] to obtain McSherry’s result.
Zhou and Woodruff [ZW04] showed that
if p=Θ(1),q=Θ(1),p−q=Ω(n−1/4)p=\Theta(1),q=\Theta(1),p-q=\Omega(n^{-1/4}), then a simple algorithm based on squaring
the adjacency matrix of the graph recovers the hidden partition whp.

Random walks. The idea of using walks of length greater than one [ZW04]
is common in the general setting of graph partitioning.
Lovász and Simonovits [LS90] show
that random walks of length O⁡(1ϕ)O(\frac{1}{\phi}) can be used
to compute a cut with sparsity at most O~​(ϕ)\tilde{O}(\sqrt{\phi})
if the sparsest cut has conductance ϕ\phi.
Later, Spielman and Teng [ST08]
provided a local graph partitioning
algorithm which implements efficiently the Lovász-Simonovits idea.

3.1 Notation

Let G⁡(V,E)G(V,E) be a simple undirected graph, where |V|=n,|E|=m|V|=n,|E|=m.
We define a vertex partition 𝒫=(S1,…,Sk){\mathcal{P}}=(S_{1},\ldots,S_{k}) as a family
of pairwise disjoint vertex sets whose union is VV.
Each set SiS_{i} is assigned to one of kk machines, i=1,…,ki=1,\ldots,k.
We refer to each SiS_{i} as a cluster or machine.
Throughout this work, we assume k=Θ⁡(1)k=\Theta(1). Let ∂e⁡(𝒫){\partial e(\mathcal{P})} be the set of edges that cross partition boundaries,
i.e., ∂e(𝒫)=∪i=1ke(Si,V∖Si){\partial e(\mathcal{P})}=\cup_{i=1}^{k}e(S_{i},V\setminus S_{i}).
The fraction of edges cut λ\lambda is defined as λ=|∂e⁡(𝒫)|m\lambda=\frac{|{\partial e(\mathcal{P})}|}{m}.
The imbalance factor or normalized maximum load ρ\rho is defined as
ρ=max1≤i≤k⁡|Si|nk\rho=\max\limits_{1\leq i\leq k}\frac{|S_{i}|}{\frac{n}{k}}.
Notice that ρ\rho satisfies the double inequality 1≤ρ≤k1\leq\rho\leq k.
When ρ=1\rho=1 we have a perfectly balanced partition. At the other extreme, when ρ=k\rho=k
all the vertices are placed in one cluster, leaving k−1k-1 clusters empty.
In practice, there is a constraint ρ≤ν\rho\leq\nu where ν\nu
is a value imposed by application-specific restrictions. Typically, ν\nu is close to 1.

We omit floor and ceiling notation for simplicity, our results remain valid.

3.2 Planted Partition Model

The model G⁡(n,Ψ,P)G(n,\Psi,P) is a generalization of the classic Erdös-Rényi graph [Bol01].
The first parameter nn is the number of vertices.
The second parameter of the model is the function Ψ:[n]→[k]\Psi:[n]\rightarrow[k] which maps each vertex
to one of kk clusters.
We refer to Ci=Ψ−1​(i)C_{i}=\Psi^{-1}(i) as the ii-th cluster, i=1,…,ki=1,\ldots,k.
The third parameter PP is a k×kk\times k matrix such that 0≤Pi​j≤10\leq P_{ij}\leq 1 for all i,j=1,…,ki,j=1,\ldots,k
which specifies the probability distribution over the edge set.
Specifically, a graph G∼G⁡(n,Ψ,P)G\sim G(n,\Psi,P) is generated by adding an edge with probability
P⁡(Ψ⁡(u),Ψ⁡(v))P(\Psi(u),\Psi(v)) between each pair of vertices {u,v}\{u,v\}.
Notice, that when all the entries of PP are equal to pp, then
G⁡(n,Ψ,P)G(n,\Psi,P) is equivalent to the G⁡(n,p)G(n,p) model.
In this work we are interested into graphs that exhibit clustering. The planted partition model we
analyze is the same as in [CK01, McS01, Sta14, ZW04]:
Pi​j=p​𝟏​(i=j)+q​𝟏​((i≠j))P_{ij}=p{\mathbf{1}}\left(i=j\right)+q{\mathbf{1}}\left((i\neq j)\right) for all i,j=1,…,ki,j=1,\ldots,k.
We assume that p>q=Θ⁡(1)p>q=\Theta(1). For simplicity, we refer to this version of G⁡(n,Ψ,P)G(n,\Psi,P)
as G⁡(n,k,p,q)G(n,k,p,q).

3.5 Path-tt classification

5 Conclusions

In this work we intoduce the natural idea of higher length walks
for streaming graph partitioning, a recent line of research [SK12]
that has already had a significant impact on various graph processing systems.
We analyze our proposed algorithm EGyPT in the planted partition model.

In future work, we plan to perform an average case performance analysis of EGyPT using a random graph model with power law degree distribution and small separators,
e.g., [FFV06, FT14], and to explore the performance of EGyPT on social networks.
