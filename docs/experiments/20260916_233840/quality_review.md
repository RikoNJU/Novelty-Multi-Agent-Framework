# 人工质量核查

## 主样本贡献边界

固定输入是 `input/paper.json`（SHA256 `89fcc578efcc840daa9c4e0698943314f794e096e176c067dbbd6e603d42ea66`）。论文摘要及正文第一章的“主要贡献”分别支持：

1. **GSAERU**：图摘要压缩单时间步图，图自编码器学习节点表示，循环网络学习时序依赖。它是大规模时序图表示学习方法，不应把速度、内存、准确率各算一个贡献。
2. **DSGNN**：领导—工作者分布式训练，工作节点对摘要子图做小批量训练，并进行梯度同步。它的目标是分布式 GNN 训练，与 GSAERU 的时序表示目标不同。
3. **Sketch-DBH**：正文第一章“提出了一种新的基于边分割的图流划分算法”和第 4.3.2 节明确给出独立目标及机制：Count-Min Sketch 保存度数、最小堆维护高频节点，按边分配子图。它服务于 DSGNN，但有独立划分规则，值得独立检索。该算法基于 DBH 改进；提取为查新点不等于确认其新颖。

第一轮提取提示词 5 次均把 GSAERU 的普通图摘要实现步骤额外拆点；第二轮仅收紧提示词时仍有一次误拆；加入有界作者贡献段供去重判断后，5 次均得到上述 3 点。`runs/extractor*` 保存逐次候选、去重轨迹。合成 E04 只返回一个方法，E05 返回两个方法；两者是构造反例，不能充当真实论文泛化结论。尚无结构不同的真实保留论文，泛化验证未完成。

## 文献证据核查

运行 1 的 NP-3 理由把摘要没有说明 Count-Min Sketch 和最小堆，写成文献没有采用，属于无依据否定。运行 3 更把相同摘要缺口升级成 `novel`，是本轮发现的严重质量故障。`runs/replay_np3_guard.json` 使用运行 3 的原始 Reviewer 输出与原始 Evidence 复核：新增边界检查将其降为 `insufficient_evidence`，同时保留相关文献索引。运行 4 开始使用此检查。检查是有限的措辞守卫，不是全文语义证明；有否定句但指向其他特征时仍需人工核验。

运行 3 曾由模型主动请求 arXiv 全文，并由 Reader 读取 4 篇，但最终卡片仍只引用摘要。因此只能证明真实“升级→落盘→Reader”链路被执行，不能宣称最终裁定已使用全文。`runs/manual_fulltext/manual_fulltext.json` 另保存一条合法记录的真实按需获取和 Reader 指定片段读取；返回的 arXiv HTML 含页面导航噪声，实际引用必须按已读范围复核。

WebSearch 结果保持补充资料身份，未进入最终论文 Evidence。运行 6 中 Browser 被调用 3 次，其中 2 次成功保存网页 Artifact，1 次因页面持续导航而无法读取；这证明工具可以工作，也暴露了动态页面错误。Springer 查询多次失败，不能把失败写作零命中。具体检索执行记录位于每轮 `retrieval-plans.json` 和 Runtime Debug 制品。
