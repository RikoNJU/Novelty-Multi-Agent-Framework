# Anti-overfit check

Production diff inspection: no new branch depends on a paper ID, title, graph term, fixed artifact offset, or expected verdict. The fixed NP-3 identifiers occur only in the known regression test and inherited archives. The implementation uses submitted IDs, citation fields, authorized source objects, exact quote bytes and a per-card size budget.

Positive control: a nonempty cited quote remains citable, including a partial quote with explicit limits. Negative control: a zero-byte omitted quote is not citable. An explicitly selected but uncited read is still shown if capacity permits and is marked as unbound, without treating it as support. A synchronized paper, point, card, Work and evidence ID remap produces the same displayed source text.

Limits: no real model semantic positive/negative controls or unseen holdout calls have run. The frozen holdout is independent of the known graph source case but uses an archive created by previous project experiments. It is reserved for later transfer observation, not a claim of unseen-model accuracy.
