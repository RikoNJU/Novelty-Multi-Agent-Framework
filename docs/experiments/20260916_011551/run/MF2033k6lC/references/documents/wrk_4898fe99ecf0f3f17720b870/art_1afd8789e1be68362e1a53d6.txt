Multivariate time-series anomaly detection is a crucial component of autonomous monitoring systems, where capturing informative representations to detect anomalies is of utmost importance. Deep learning approaches such as reconstruction-based autoencoders and variational autoencoders perform well on this task, but they typically overlook geometric and topological structure in the data while incurring high computational cost. In this paper, we introduce the use of topological features derived from persistence diagrams for unsupervised anomaly detection in multivariate time series. We propose a hybrid framework that combines these topological features with rich representations extracted from a trained sequence-to-sequence variational autoencoder, scored jointly by Isolation Forest. We demonstrate bidirectional complementarity: adding topological features to autoencoder features improves F1 by up to $$15.0\%$$ 15.0 % , while adding autoencoder features to topological features improves F1 by up to $$8.3\%$$ 8.3 % . Furthermore, we show that the optimal topological representation depends on channel characteristics, and that the use of persistence landscapes yields additional gains over only using scalar summary statistics.
