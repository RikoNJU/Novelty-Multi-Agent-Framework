# 检索稳定性修补阶段报告

本轮在仓库内直接调用生产 fallback 和检索函数，使用相同的合成查询响应映射完成 B0、BF、BE、BFE 控制流测试。已确认保护约束生效，早期 8 篇不能隐式截断其余基础方向；预算只允许 1 次请求时，后续方向明确标为 `not_run / retrieval_incomplete_budget`。修订审计报告只观察到三次历史计划的概念载荷差异；每次 C0 为 3 条策略、2 种 DSL 表达式。适配后请求、实际执行与去重文献数在这次本地审计中均未测量。

上述结果验证机制，不评价学术相关性。离线生产链 smoke 已经过检索、Reader、EvidenceCardBuilder、点级 Reviewer 和报告渲染，并从导出包重新打开文献资产；这不代表真实论文的阅读、成卡、Reviewer、报告与前端效果已改善。后来用户明确授权，完整运行已使用一次，模型费用 2.0774424 元；下述真实材料交叉核对覆盖 X1–X5 的现有证据边界。

本地已验证 Planner 链、并发点位关联、大载荷归档、异步取消、严格离线 `replay_miss`、生产链 smoke、该 smoke 包的引用闭包，以及追踪开关两种状态下的实际检索查询和 Reader 参数等价性。八项本地 Debug 检查已通过；含 Provider 内部重试／分页的统一物理请求硬预算和模型调用上限均已实现、通过发出请求前的边界测试。见 `debug-ready.json`。首次启动被自动审批拒绝；用户明确授权后启动成功。实际运行 75 次模型调用、27 次 Provider 物理请求，低于 130/48 上限。三个点分别形成 1/2/2 张卡，但 Reviewer 均判证据不足；不能宣称实际症状已改善。详细边界核对见 `analysis/live-boundary-cross-validation.md`。
